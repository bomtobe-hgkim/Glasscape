# Glasscape HTML 디자인 미리보기

Windows용 데스크톱 유틸리티의 첫 UI/UX 프로토타입입니다. `index.html`을 브라우저에서 열면 사용할 수 있습니다. 설치, 빌드, 외부 폰트가 필요하지 않습니다.

## 방향

조용한 데스크톱 스튜디오. 슬레이트 네이비 `#111b29`, 패널 `#172334`, 안개 같은 텍스트 `#edf2f5`, 절제된 청록색 `#66c4ce`와 얇은 구분선을 사용합니다. Segoe UI Variable Display를 제목에, Segoe UI / Malgun Gothic을 본문에 사용합니다. 가장 큰 시각 요소는 실제 배경화면과 투명 작업표시줄이 함께 보이는 모니터 미리보기입니다.

## 동작

- 개요 / 작업표시줄 / 배경화면 / 설정 탐색과 모바일 레이아웃
- 작업표시줄 투명화 스위치와 0–100% 불투명도 실시간 미리보기
- 사진 배경 3개 선택, 주 / 보조 / 모든 모니터 선택, 꽉 채우기 / 화면에 맞추기
- MP4 / WebM 파일 선택 또는 드래그 앤 드롭, HTML video 반복 재생, 재생 / 일시정지, 무음 / 음량 조절
- Windows 시작, 트레이 유지, 전체 화면 / 배터리 일시정지 옵션 구성
- 브라우저 localStorage에 설정 저장, 설정 페이지에서 초기화
- 키보드 스위치 조작, 선택 상태와 알림 접근성 속성, 명시적 포커스 표시, reduced-motion 대응

이 HTML은 Windows 설정, 실제 작업표시줄, 데스크톱 배경화면을 바꾸지 않습니다. 모니터 정보는 예시이며 시작 / 트레이 / 전체 화면 / 배터리 옵션은 브라우저에 저장되는 디자인 설정입니다. 운영체제 동작은 향후 C# 앱 연결이 필요합니다. 동영상은 object URL로 이 브라우저 세션에서만 재생되며 업로드하지 않습니다. 새로고침 후에는 파일을 다시 선택해야 합니다. 코덱 지원은 브라우저에 따라 다릅니다.

`assets/app-icon.png`에 생성된 앱 아이콘을 넣으면 브랜드와 작업표시줄에 표시됩니다. 파일이 없으면 내장 유리 패널 마크를 사용합니다.

## 빠른 확인

1. `index.html`을 열고 작업표시줄 불투명도를 0 / 50 / 100%로 바꿉니다.
2. 투명화를 끄고 켜고, 각 사진과 모니터 선택을 눌러봅니다.
3. 실제 MP4 / WebM 파일을 가져와 재생, 일시정지, 화면 맞춤, 무음, 음량을 확인합니다. 다른 파일 형식은 오류 메시지를 표시합니다.
4. 설정 페이지의 시작 옵션을 바꾸고 새로고침해 유지되는지 확인합니다.
5. 480px 너비에서 탐색과 컨트롤이 보이는지, Tab / Space 키로 스위치를 조작할 수 있는지 확인합니다.

프로덕션 코드나 Windows 설정은 수정하지 않습니다.
